# Learning System

The lab should get smarter after every launch.

## Daily Inputs

- Top GitHub Trending repositories
- Fast-rising AI/dev-tool repos
- Existing repo stars, forks, issues, releases, topics, and CI status
- Launch channels used
- User comments, issues, and objections
- README and demo clarity

## Daily Decision

Each session chooses one of three actions:

1. Launch a new useful AI developer tool.
2. Improve an existing tool with a meaningful release.
3. Do both when the new trend and previous feedback both justify work.

## What To Learn

Track every launch by:

- Niche
- Hook
- Channel
- Time of launch
- Repo format
- README structure
- Demo type
- 24-hour stars
- 7-day stars
- Issues/forks/comments

## Compounding Rule

If a repo gets stronger signal than the others, it gets more attention:

- Better docs
- Better examples
- More integrations
- Demo video or interactive page
- Package publishing
- Productized roadmap

If a repo gets no signal after two useful updates, pause it and test a new niche.
