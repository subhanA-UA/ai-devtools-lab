# Channel Playbook

Use these channels carefully and only where the project is genuinely relevant.

## GitHub

- Add searchable topics.
- Keep the README direct and skimmable.
- Use a clear release title.
- Create good-first-issue items only when there is real work.

## X / Twitter

Hook:

> Built a tiny CLI that turns any repo into an AI-ready brief before your coding agent starts working.

Measure:

- Profile clicks
- Repo clicks
- Stars within 2 hours
- Replies asking for features

## Hacker News

Format:

> Show HN: Context Scout AI - one command to brief your coding agent on a repo

Use only when the repo has a working demo, docs, and clear source.

## Reddit

Use subreddits only where self-promotion is allowed or where the post is framed as a practical tool/demo.

Measure:

- Upvotes
- Comments
- GitHub stars within 24 hours
- Feature requests

## Dev.to

Use for explainer posts:

> I got tired of pasting messy repo context into AI coding agents, so I built a tiny CLI to rank the important files.
