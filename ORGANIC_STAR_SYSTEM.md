# Organic Star System

The goal is maximum real stars from real developers.

## 30-Minute Moves

1. Make the README clearer.
2. Add a direct star link near the top.
3. Add a live demo or screenshot.
4. Add GitHub topics.
5. Add feedback issues.
6. Add a release with a clear reason.
7. Cross-link from AI Devtools Lab.
8. Post one useful launch message in one relevant channel.

## What To Measure

- Stars before and after each channel
- Forks
- Issues
- Replies/comments
- Which hook was used
- Which niche was used
- Which repo got clicked or starred

## Current Hypotheses

- "Make your repo ready for AI coding agents" is stronger than "generate repo context".
- Score/checklist outputs are more shareable than raw utility output.
- A hub helps compound discovery only after at least 3-5 useful tools exist.

## Rules

- No paid stars.
- No star swaps.
- No spam comments.
- No fake activity.
- Every release must contain real product, docs, or distribution value.
